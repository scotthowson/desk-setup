# L-249 desk showcase

20 seconds, 1600 × 900, 24 fps, H.264 MP4 with original stereo ambient audio.

Geometry exported from scotthowson/desk-setup index.html on main, Git blob e3dda0f5167aab8b4ff53113c0957ae94d3c382a.

The furniture mesh geometry is from the repository. Film treatment adds procedural walnut grain, screen artwork, studio lighting, room extension and camera animation. The model is a visual representation, not fabrication documentation. Internal coplanar case panels are omitted from the film render to prevent flicker.

Rebuild with Python (numpy, Pillow, moderngl), Node.js and ffmpeg:

1. node export_scene.cjs
2. python render.py
3. python score.py
4. ffmpeg -i desk-showcase-silent.mp4 -i ambient-score.wav -c:v copy -c:a aac -b:a 192k -af afade=t=out:st=18:d=2 -shortest -movflags +faststart desk-showcase.mp4

Three.js is included under its MIT license. Soundtrack is generated by score.py; it uses no third-party recordings.
